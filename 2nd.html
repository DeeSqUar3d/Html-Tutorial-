<(a)> Anchor Element

Indicates a hyperlink, this is used to link another page.

<(a href="your webpage.html"> HOME <(a href="your webpage2.html"> ABOUT




Element Attributes

Provides additional information about the elements

Every element can have an attribute, some attributes are element specific
and cannot be applied to other elements, an element can also have multiple attributes.

    Attributes
  • href - indicates the URL it will go to
  • target - where the link will open

HREF attribute
<(a href="yourwebpage.html")> your webpage

TARGET attribute
<(a href="yourwebpage.html" target="_blank")> your webpage

Target attribute - takes ( _blank, _self, _parent, _top/iframe ) as values.
