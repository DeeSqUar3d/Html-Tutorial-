IMAGES

<(img)> Image Element


indicates an image



<(img src="name.png")> <(img src="name.jpg")>




    Image Element Attributes

  • src - the file path to load the image
  • width - how long the image is
  • height - how tall the image is
  • alt - text that shows when the image fails to load
  • style - allows you to adjust the image's location, border, etc.



Examples

SRC attribute = <(img src="pictures/name.jpg")>



Width & Height (100px) = <(img src="pictures/name.jpg" width="100px" height="100px)>




Image Links


Surround the image with <(a)> tag to make it clickable



<(a href='2nd.hmtl')> <(img src="pictures/name.jpg")>
